## 📖 项目简介

**CyberDeck OS 2077** 是一个在现代 Web 浏览器中运行的高拟真、赛博朋克风格桌面操作系统。它集成了 **赛博修仙木鱼**、**机甲自由漫游桌宠**、**代码肉鸽地下城**、**赛博华尔街股票与房产投资**、**8-Bit 合成器编曲机** 等 18 个深度互联的应用与游戏子系统。

所有系统间数据深度打通：木鱼积攒功德、股市赚取赛博币、地下城与炼宝炉打造神兵、钓鱼与宠物搜集探针，构筑起一个闭环、自洽且耐玩的沉浸式摸鱼元宇宙。

## 🌟 最新版本特性 (v2.7.1)

- 🐕 **桌面桌宠自由拖拽漫游**：
  - **随心拎起摆放**：支持鼠标与触屏长按桌宠自由拖拽至桌面任意角落（高空、窗口边缘、便签旁）。
  - **位置持久化记忆**：放下后自动记住摆放坐标，下次打开页面依然留在原位。
  - **巡逻漫游 AI**：在当前放置的高度自动水平巡逻，支持多种萌系动作（散步、打瞌睡、掘宝、摇尾巴）。
  - **趣味交互动效**：拎起时带有呼吸光晕与倾斜挣扎动效，触发「起飞喽！」、「主银你要带我去哪~」等定制语音；短按点击即触发抚摸好感与爱心粒子。
- 👾 **赛博扫雷难度动态自适应**：
  - **自适应窗口与方块**：切换【初级探针】(8×8)、【中级渗透】(12×12)、【高危矩阵】(14×14) 时，窗口尺寸（560×600、650×680、730×750）与格子尺寸自动精准匹配。
  - **零内层滚动条**：彻底优化容器边距与内边距层叠，控制面板单行排布，不再出现折行拥挤或遮挡。
  - **智能布局升级**：自动迁移旧存档中的窄小尺寸，默认打开即呈现最清晰平整的矩阵界面。
- ₵ **赛博专属货币符号体系**：
  - 全局统一使用赛博信用币符号 `₵` (Cyber Credits)，替换掉原先混杂的美元符号，数值显示与文案风格更加统一沉浸。
- ⚖️ **经济数值与可玩性平衡重构**：
  - 祈愿抽卡与盲盒扭蛋消耗梯度优化，产出概率平滑阶梯化，提升长线策略追求与耐玩度。

## 🚀 启动与运行

### 方式 1：双击运行 (Windows)
双击项目根目录下的 `start.bat`，脚本会自动检测依赖并开启本地服务器，并在默认浏览器中弹出页面。

### 方式 2：命令行启动
```bash
# 1. 克隆代码仓库
git clone https://github.com/qjngbac/cyberdeck-2077.git

# 2. 进入项目目录
cd cyberdeck-2077

# 3. 安装依赖 (推荐 pnpm 或 npm)
npm install

# 4. 启动本地开发服务器
npm run dev

# 5. 打包生产静态资源
npm run build
```
本地访问地址：`http://localhost:5173`

## 🛠️ 技术架构

- **核心框架**：React 19.2 (Hooks, Context 状态树，高度模块化组件)
- **开发构建**：Vite 8.2 + Rollup (毫秒级热更新，代码分割异步按需加载)
- **类型安全**：TypeScript 6.0 强类型约束
- **样式方案**：Tailwind CSS 4.3 + 自定义赛博朋克霓虹主题发光与 CRT 特效
- **音频引擎**：原生 Web Audio API 振荡器与滤波器波形实时物理合成
- **轻量依赖**：零服务端、零外部图床依赖，单机完全自洽运行
