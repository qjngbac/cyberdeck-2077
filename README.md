## 🚀 启动与运行

### 方式 1：双击运行
双击根目录下的 `start.bat` 即可自动启动服务器并打开浏览器畅玩。

### 方式 2：命令行启动
```bash
# 启动开发服务器 (毫秒级热重载)
npm run dev

# 构建生产离线包
npm run build
```
浏览器访问：`http://localhost:5173`
